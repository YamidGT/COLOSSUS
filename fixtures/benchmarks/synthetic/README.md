# SYNTHETIC benchmark fixtures

Every file here is hand-made synthetic test data for `tests/benchmarks/`. None of it is
from CTIBench, CyberSecEval, DafnyBench or MITRE CWE, none of it is benchmark evidence,
and the CVE-like identifiers under `example.invalid` do not exist. The files only mimic the
official column/field layouts so loaders and scorers can be exercised offline.
