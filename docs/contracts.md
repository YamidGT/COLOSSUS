# Shared contracts and persistence

Owner A. All lanes implement against schema version `1.0`. Use Pydantic v2 with `extra=forbid`, strict integers/booleans, bounded strings/lists and explicit enums. Export JSON Schema and fixtures during M0. The examples under `examples/` are illustrative and non-executable. Errors use `{code, message, retryable, evidence_ids}`; no secrets in messages.

## Common conventions

IDs: UUID strings generated by the controller. SHA-256: lowercase 64 hexadecimal characters. Image references: resolved OCI digest plus platform; record index and platform image digests when applicable. UTC timestamps: RFC3339; use monotonic clocks for elapsed time. Money: integer micro-USD, token counts: nonnegative integers, timeouts: integer seconds. Paths are relative POSIX paths without `..`, symlinks or absolute roots. Content IDs resolve only through the controller's artifact API. Canonical JSON hashing uses UTF-8, sorted keys, compact separators, no NaN/Infinity; schemas avoid floats in hashed objects.

Envelope: `schema_version, message_id, project_id, cycle_id?, case_id?, task_id?, parent_message_id?, kind, producer, created_at, payload, payload_sha256`. Verify caller identity separately; the `producer` string is not authentication. Optional fields are null rather than sentinel strings. Payload hash excludes envelope metadata.

`proof_outcome`: PROVED, BOUNDED_PASS, COUNTEREXAMPLE, UNKNOWN, UNSUPPORTED. Gate status is calculated against the obligation requirement: a bounded result cannot satisfy an unbounded proof requirement. Formal summaries without underlying results are invalid. A non-formal gate must use null proof_outcome. Costs live in ModelCall records, not duplicated per Finding.

ModelCall status is `reserved/in_flight/succeeded/failed/uncertain`; reason codes include `refused`, `provider_policy_block`, `rate_limited`, `unsupported_parameter`, `invalid_output`, `transport_error` and `timeout`. Missing provider usage stays null/uncertain, never silently zero. The gateway maps these outcomes to task state; no new success state bypasses gates. Model profiles and fallback eligibility are specified in [model strategy](model-strategy.md).

## APIs and authority

Operator API on loopback/SSH tunnel: POST `/projects`, POST `/projects/{id}/cycles`, GET `/cases/{id}`, GET `/projects/{id}/status`, POST `/cases/{id}/cancel`, POST `/authorizations`, POST `/deployments/{id}/rollback`, GET `/reports/{id}`. POSTs require `Idempotency-Key`; mismatched body for a reused key returns conflict. Operator authentication token stays outside target jobs.

Internal RPCs are typed over local Unix sockets with service-specific socket permissions. If split across machines, require mTLS before enabling network listeners. Controller calls:

- Gateway: `fetch_source(source_id, revision)`, `fetch_feed(feed_id, cursor)`, `complete(task_id, template_id, context_ids, model_tier)`.
- Launcher: `create_environment(manifest_hash, role)`, `run_job(environment_id, job_profile_id, input_content_ids, limits_id)`, `collect(job_id)`, `destroy(environment_id)`.
- Deployment service: `stage(authorization_id)`, `observe(deployment_id)`, `promote(deployment_id, expected_generation)`, `rollback(deployment_id)`.

Job profiles resolve to fixed executables/entrypoints and validated arguments. A setup recipe can contain build commands, but they execute only inside the builder. The host launcher never evaluates a shell string supplied by a worker. Worker-to-controller calls accept task-scoped capability tokens with expiry, maximum uses and artifact namespace; models never choose the token or access another task.

Every lane also exposes a JSON stdin/stdout adapter with diagnostics on stderr for fixture integration. CLI plan: `colossus doctor`, `enroll URL`, `run PROJECT`, `status ID`, `approve MANIFEST`, `rollback DEPLOYMENT`, `evaluate MANIFEST`, `report RUN`. These commands are not installed yet.

## State and transactions

SQLite tables: projects, target_manifests, cycles, cases, tasks, task_attempts, findings, candidates, gate_results, evidence_manifests, authorizations, deployments, artifacts, model_calls, budget_reservations, audit_events, outbox, schema_migrations. Large content belongs in artifact files, not task rows. Only controller writes SQLite; workers submit results via RPC. WAL mode, busy timeout and backups are configured by A.

Task claims atomically set lease_owner, lease_expires_at, attempt and state. Heartbeat every 10 seconds; lease 60 seconds. A timeout does not release resources until the launcher confirms termination. Persist state transition and outbox event in one transaction; replay dispatch after restart. Delivery is at least once; operations are idempotent, never claimed exactly-once.

Deployment uses prepare/action/reconcile: persist intent, ask deployer, record result. On restart query actual destination generation/digest before repeating an action. Compare-and-swap expected generation prevents stale promotion. Never restore an old database snapshot blindly during reconciliation.

Artifacts: write temporary file, fsync, verify digest, atomic rename to `artifacts/sha256/<hash>`, then index in transaction. Reject oversized/nonregular files and symlinks. If index write fails, treat file as orphan for later cleanup; do not mark a gate passed. If audit persistence is unavailable, stop new authority-changing actions while completing already authorized emergency recovery.
